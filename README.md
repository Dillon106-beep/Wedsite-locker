# Project Overview
Dillon's Bakery website is a responsive site designed to showcase its cakes, bread and pastries and allow customers to easily view and order online, Homepage, about us, Menu, Order now and contact warm clean colors and consistent product cards built using HTML and CSS to boost its online presence and simply ordering.

# Goals and Objectives
The goal of Dillon's Bakery website is to create n attractive, responsive site that promotes the bakery and makes ordering easy, with objectives to showcase products with images and prices, provide simple navigation, allow online orders and contact, maintain a consistent brand look using CSS and ensure the site is mobile friendly for all customers.
